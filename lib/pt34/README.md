# SP34TUBE-IFY

Integración de las funciones propias de SPT34ify dentro de la base Flutter funcional de Spotube.

## Base funcional conservada

Se mantienen activos y sin modificaciones innecesarias los sistemas originales de Spotube:

- Reproductor de audio
- Cola de reproducción
- YouTube Audio
- Búsqueda musical
- Metadatos musicales
- Carátulas e imágenes
- Artistas
- Álbumes
- Canciones
- Playlists
- Biblioteca
- Historial
- Descargas compatibles
- Plugins originales
- Proveedores de audio
- Servicios internos de Spotube

## Funciones SP34TUBE-IFY

Dentro de esta carpeta se incorporarán progresivamente:

- Home Screen PT34
- My Activity
- Mis canciones
- Crear canciones con IA
- Preparación de audio
- Creación y selección de carátulas
- Metadatos para distribución
- Perfil PT34
- RouteNote
- Indiefy
- Herramientas de publicación musical
- Identidad visual SP34TUBE-IFY
